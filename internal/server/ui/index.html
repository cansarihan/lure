                        The decoys

                        Each sensor answers just enough of its protocol to see what a client wants, records it, and hangs up. Nothing a client sends is ever run.

                        About Lure

                        Lure runs services that nobody should use: a web login page, an SSH banner, a telnet prompt and ports dressed as other software. Because no legitimate client has a reason to connect, everything they record is a probe, a scan or an automated login attempt.

                        Each sensor reads a bounded amount of input, never runs any of it, and closes the connection. Events are tagged by the behaviour they show, kept in memory, and optionally written to a JSON Lines journal.

                        Run Lure on an address you control, and keep the panel on a private address or behind a token.
